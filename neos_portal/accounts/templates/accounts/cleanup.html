Clean up unused files

When you replace a certificate or delete a record, the portal keeps the old file in storage. These files are not used by any record any more. Moving them out of the way saves storage, and nothing is lost for good right away.

How this stays safe

  • Files are moved to a trash, not deleted. You can restore them for {{ hold_days }} days; only after that can they be deleted for good.
  • Only files that no record uses are listed, and this is checked again at the moment you click.
  • Files stored in the last {{ grace_hours }} hours are never listed.
  • Make a backup first. A backup that included old versions keeps a copy on your disk.
